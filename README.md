# MG Rust Survival — klientsky náhľad

Statický náhľad webu pre klienta, určený na GitHub Pages.

[Otvoriť klientsky náhľad](https://vaskoandrej.github.io/mgrust-preview/) Adresár obsahuje iba súbory potrebné na jeho zobrazenie. Otvor `index.html` alebo publikuj obsah tohto priečinka cez GitHub Pages.

Produkčné zdrojové súbory sú v pôvodnom projekte v priečinku `web/`. Úpravy rob najskôr tam a potom priprav nový náhľad. Tento export nepoužíva vlastnú doménu ani analytické meracie ID. Relatívne cesty fungujú aj v podadresári `/mgrust-preview/`.

Náhľad má `noindex,nofollow` a `robots.txt` zakazuje indexovanie. To nezabezpečuje súkromný prístup: adresu môžu otvoriť ľudia, ktorí ju poznajú. Produkčný web je pripravený pre www.mgrust.eu a zvolený hosting AVORO. Pred spustením sa ešte potvrdí doručovanie kontaktného e-mailu a nastavenie serverových záznamov.
